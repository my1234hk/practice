# 出退勤トラッカー（iPhone対応）

iPhone 12 で使える、シンプルな出退勤記録Webアプリです。

---

## まず結論（最短で使う手順）

### A. パソコンがある場合（おすすめ）
1. この4ファイルを同じフォルダに置く
   - `index.html`
   - `app.js`
   - `styles.css`
   - `README.md`
2. そのフォルダで次を実行してローカルサーバー起動
   ```bash
   python3 -m http.server 8000
   ```
3. iPhoneとPCを同じWi-Fiに接続
4. PCでIPアドレス確認（例: `192.168.1.20`）
5. iPhoneのSafariで `http://192.168.1.20:8000` を開く
6. Safariの共有ボタン → **ホーム画面に追加**
7. ホーム画面アイコンから起動して「出勤を記録」「退勤を記録」をタップ

### B. 公開URLで使う場合（GitHub Pages）
1. GitHubで新規リポジトリ作成
2. この4ファイルをpush
3. GitHubの `Settings` → `Pages`
4. `Deploy from a branch` を選択、`main` / `/ (root)` を保存
5. 数分後に発行されるURLをiPhone Safariで開く
6. 共有ボタン → **ホーム画面に追加**

---

## 使い方（毎日の運用）
- 出勤時: **出勤を記録** を1回タップ
- 退勤時: **退勤を記録** を1回タップ
- 記録確認: 下の「記録一覧」に日時が表示
- 集計確認: 「最近14日間の勤務時間」に棒グラフ表示
- 提出用: **CSV出力** を押してファイル保存

---

## このアプリで今できること
- 出勤 / 退勤をワンタップで記録
- 記録を端末の `localStorage` に保存
- 直近14日間の勤務時間を棒グラフ表示
- 記録を CSV としてエクスポート
- 全記録削除

## 注意点（重要）
- 保存先はブラウザ内のみ（iCloud/サーバー同期なし）
- iPhoneのSafariデータを削除すると記録が消える可能性あり
- 出勤→退勤のペアで勤務時間を計算
- 日をまたぐ夜勤などは厳密な勤怠計算に未対応
